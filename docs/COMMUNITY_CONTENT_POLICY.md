# Community content policy

Pliego Lab can be used locally for mature fiction, but the repository and its public channels must remain suitable for collaboration.

## Issues, pull requests, and examples

- Do not upload API keys, private chats, personal data, third-party cards, or real local paths.
- Use synthetic fixtures and clearly fictional characters.
- Do not include explicit sexual content, sexualization of minors, exploitation, non-consensual material, or private images in issues, screenshots, or documentation.
- If a bug requires sensitive material, describe the case minimally and use the private [`SECURITY.md`](../SECURITY.md) channel when appropriate.
- Clearly label any mature example permitted by context and keep it out of introductory documentation.

This policy governs public collaboration. It does not change local functionality or attempt to decide what content users may create outside the repository.
